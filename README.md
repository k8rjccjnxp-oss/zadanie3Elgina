# ВелоСклад — учебный проект (Задание 3)

Веб-приложение для учёта товаров и заказов магазина велосипедов. Реализовано на Python, Flask и SQLite.

## Возможности
- Авторизация по логину и паролю; гостевой режим просмотра.
- Роли: гость, авторизованный клиент, менеджер, администратор.
- Список товаров с поиском по нескольким текстовым полям, фильтрацией по категории и диапазону скидки.
- Сортировка по названию, цене, остатку и скидке.
- Отображение скидки и итоговой цены; строки товаров без остатка выделяются серым.
- Администратор может добавлять, редактировать и удалять товары (товар из заказа удалить нельзя).
- Менеджер и администратор могут просматривать заказы; администратор может добавлять, редактировать и удалять заказы.
- SQLite-база создаётся автоматически при первом запуске и заполняется демонстрационными данными.

## Запуск
Требуется Python 3.10+.

```bash
python -m venv .venv
# Windows:
.venv\\Scripts\\activate
# macOS/Linux:
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

Откройте http://127.0.0.1:5000

## Демо-учётные записи
| Роль | Логин | Пароль |
|---|---|---|
| Администратор | `admin` | `admin123` |
| Менеджер | `manager` | `manager123` |
| Клиент | `client` | `client123` |

Гость: нажмите «Продолжить как гость» на странице входа.

## Структура
- `app.py` — маршруты, права доступа, бизнес-логика и инициализация БД.
- `templates/` — HTML-шаблоны страниц.
- `static/style.css` — стили интерфейса.
- `sql/schema.sql` — схема базы данных.
- `sql/seed.sql` — демонстрационные данные для SQLite.
- `requirements.txt` — зависимости.
